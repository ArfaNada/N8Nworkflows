# N8N Workflows 🚀

A collection of n8n workflows to automate your tasks.

## 📦 Available Workflows

- **My AI Study Assistant** - AI-powered study assistant workflow
- **My Voice Text Scheduler** - Voice-to-text scheduling automation

## 🚀 How to Use These Workflows

1. Open the `.json` file you want to use

2. Click the **"Raw"** button and copy all the text (or download the file)

3. Go to your n8n canvas

4. Press `Ctrl + V` (Windows) or `Cmd + V` (Mac) to paste the workflow, or use the **import from file** option

> **⚠️ Important:** You must click on the Google Calendar and OpenAI nodes to connect your own credentials!

## 📝 Notes

- Ensure you have the necessary integrations configured in your n8n instance
- Review and customize the workflows according to your needs
